# task26100276

奖学金评审的进程内排名库（Go）。

## 功能

- 初始化时固定申请集合、每份申请的评审集合、1 至 5 个评分项、初始权重与名额 K。
- `PutScores(applicationID, reviewerID, changes)`：原子提交评分补丁（每项 1 至 10），未出现的项保持原值，重复提交只保留当前分值。
- `SetWeights(weights)`：原子替换全部评分项权重（每项 1 至 100），对之后的预览生效。
- `PreviewAwards()`：返回最多 K 名获奖候选人。仅填齐全部评分项的评审参与计算；
  先求每名完整评审的加权平均，再等权平均；按精确有理数分数降序、同分按申请 ID 字典序。
- 所有操作可线性化：每份预览的名单、顺序、权重、评分与完整评审人数对应同一完整状态。

## 运行测试

```sh
go test ./...
```

可选：竞态检测与重复运行

```sh
go test -race -count=3 ./...
```

## 代码结构

- `awards.go`：库实现（`Board`、`Award`，读写锁保证单状态快照）。
- `awards_test.go`：串行测试，含独立参考实现交叉验证（残缺补齐、重复提交、精确分数决定最后名额、同分字典序、权重替换、参数校验）。
- `awards_concurrency_test.go`：并发测试，交错提交补丁/替换权重/预览，验证每份预览对应其调用区间内某个已提交的完整状态。
